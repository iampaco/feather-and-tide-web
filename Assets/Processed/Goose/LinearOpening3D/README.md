# 单线 Demo 开场 3D 样段

7 份斑头雁 USDZ 动作与 S0 湿地逐字节取自 M10a 私有预览，逐项与原台账哈希对照。S1 使用同一预览的网格、材质与纹理，沿北端最后几布局单位逐步降低顶点高度，与灰盒河道自然叠接。浅岸覆盖范围内的顶点未改。制作输入、沿用许可及原稿路径见 [素材台账](../../../../docs/references/asset-ledger.md) 和 [预览清单](preview-manifest.json)。

从项目根目录执行 `./Scripts/goose_linear_preview.sh <输出目录>`。需要项目现有的 M10a 模拟器 ZIP 和 Blender 5.2.2。脚本在临时目录中编辑导出副本，USDZ 容器的重新包装可能改变导出哈希。S0 / S1 进入游戏后的摆位由 `GooseLinearScenery` 设置。检查 [交付与试玩记录](../../../../docs/playtests/goose-linear-3d/README.md)。
