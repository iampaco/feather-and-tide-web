# 素材库使用约定

2026-11-08（Asia/Shanghai）。项目约定以根目录 `AGENTS.md` 为准；本文说明操作路径。项目指定素材库为 `Assets/`，入口为 [README](../README.md)。

本轮用户已明确确认 Grok Imagine 批次用于本游戏的权利，并授权加工与接入现有切片。由内置 imagegen 清理并完成程序锚点/色调适配的导出按本次授权接入，保留人工美术终审与真机项；不追认未经处理的原稿全部就绪。见 [接入报告](../../docs/references/assets-integration-2026-11-08.md)。

## 目录与路径

- `Assets/Watercolor/{Goose,Whale,Deer,Shared}/`：分类原稿与候选色板；迁入文件保留原名和 Asset ID。
- `Assets/refs/`：风格、构图和示意参考，不作为可直接加载的关卡层。
- `Assets/Graybox/`、`Assets/Audio/`、`Assets/UI/`、`Assets/Haptics/`：对应类别的制作源文件及候选；现有占位文件保留。
- `Assets/docs/`：说明、候选台账、机器索引和迁移记录。

索引 `asset-index.json` 中的 `path` 一律相对**项目根目录**，例如 `Assets/Watercolor/Goose/Characters/goose_char_fly_side_01.png`；不要在路径前再加一次 `Assets/`。Markdown 链接按各文档所在目录解析。

## 从候选到运行时资源

1. 新素材和参考统一进入 `Assets/` 的对应分类；不同来源或新版本建独立子目录，保留原稿，避免覆盖同名文件。
2. 补充候选索引与台账：来源 / 工具、提示词或制作输入、许可依据、修改情况、署名、用途和待处理项。许可不明时只保留私人参考状态。
3. 按当前 active 计划筛选。先对照已选湿地 V07 风格，再做透明、去字、动画锚点 / 比例、拆层、接缝与色调处理；加工版本单独保存。
4. 人工确认许可、清理和色调，完成实际场景合成验收后，按 `ft_…` 规范导出到 `Sources/FeatherTide/Resources/` 的现有资源结构。库内原名继续保留，正式台账记录原稿 ID → 导出路径、处理方法及验收状态。
5. 更新 `docs/references/asset-ledger.md`；若修订现有运行时资源，还需按 `docs/references/production-inputs.md` 更新配方与身份清单。运行构建、相关测试，触控、镜头、声音和性能仍按真机记录验收。

素材库不整体加入 Xcode Copy Bundle Resources，也不建立指向整个库的运行时链接。候选色板的风格板标记只标识该批原稿，不会自动替换已选风格或现有色板实现。
