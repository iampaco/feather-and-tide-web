## 1. 项目与本包用途

《羽与潮》是治愈向 **2D 水彩迁徙**游戏：玩家分别以斑头雁、须鲸、驯鹿完成迁徙段，观察人类痕迹（Trace），不做血腥或惊吓。本包提供三线 **Watercolor 静帧 PNG + Palette JSON + 风格 refs**，供 coding agent 系统接入工程。

**Agent 工作流（强制顺序）**

1. 读本指南（命名、色温、循环、透明、禁止项）。
2. 打开 `Assets/docs/asset-ledger.md`，用 **Asset ID**（无扩展名）定位路径与备注。
3. 从 `Assets/Watercolor/{Goose|Whale|Deer|Shared}/…` 取文件；**不要**猜路径。
4. 按第 8 节：Graybox → 视差 → 主角循环 → Trace overlay → UI → VFX。
5. 遇到「未对齐 / 无 alpha / 烧录字」以台账备注为准，**不要**假装已生产就绪。

本包 **不含**可用音频与触觉：`Assets/Audio/**`、`Assets/Haptics/` 为空占位目录。

### 4.4 视差滚动速度角色（v0–v3）

相对主角水平速度 `playerVx` 的建议系数（可配置，非性能承诺）：

| 速度角色 | 层 | 建议系数 × `playerVx` | 说明 |
|---|---|---|---|
| **v0** | `sky` | 0.05–0.15 | 几乎不动 |
| **v1** | `far` | 0.25–0.40 | 远山/远岸 |
| **v2** | `mid` | 0.55–0.70 | 主地形；**Trace 叠在此层之上，不写入纹理** |
| **v3** | `near` | 0.85–1.10 | 近景植被/礁石 |
| 特殊 | `fog` | 0.30–0.50 + 缓慢正弦漂移 | 可半透明 |
| 特殊 | `water` | 0.70–1.00 + 可选 UV/偏移浪 | 鲸线可略独立于 near |

```swift
// 伪代码：视差层
func scrollParallax(layer: SKSpriteNode, role: SpeedRole, playerVx: CGFloat, dt: CGFloat) {
    let k: CGFloat = [/* v0…v3 / fog / water */][role]
    layer.position.x -= playerVx * k * dt
    // 超出半宽则 tile 回绕（素材非无缝时需人工接缝或拉长条）
}
```

**Trace**：永远是 **独立 overlay 节点**（或独立 `SKNode` 容器），按关卡数据显隐/淡入；**禁止**烘焙进 `mid` PNG。

## 5. 动画循环约定

| 循环名 | 线 | 帧模式 | 说明 |
|---|---|---|---|
| **FLY** | Goose | `fly_side_01…08` | 主飞行；约 8–12 fps 起步可调 |
| **WALK** | Deer | `walk_01…08` | 主行走 |
| **RUN** | Deer | `run_01…06` | 奔跑 |
| **BREACH** | Whale | `breach_01…04` | 跃出；播完回游/拼装态 |
| **TAKEOFF → FLY** | Goose | `takeoff_01…06` → `fly_side_*` | 过渡后进入 FLY |
| **LAND → REST** | Goose | `land_01…06` → `rest_float_*` | 过渡后进入 REST |
| 其他 | 各线 | `glide` / `feed` / `forage` / `rest` / `stagger` / `body` 拼装 | 见台账 |

```swift
// 伪代码：FLY 循环
let names = (1...8).map { String(format: "goose_char_fly_side_%02d", $0) }
let textures = names.map { SKTexture(imageNamed: $0) }
let fly = SKAction.repeatForever(SKAction.animate(with: textures, timePerFrame: 1.0/10.0))
sprite.run(fly, withKey: "FLY")
```

### ⚠ 帧未像素对齐（硬警告）

- 同循环各帧为 **独立 Imagine 生成**，**非**同一骨架相位对齐。
- 直接 `animate` 会出现跳变、体型缩放抖动、锚点漂移。
- **入库/上线前**需：统一画布尺寸、对齐锚点（胸/躯干/节间）、必要时重生成或手工稳帧。
- Agent 可先用循环做灰盒手感，但须在代码/注释中标明 `// TODO: frames not pixel-aligned`。

鲸 `body_01…04` + `tail` + `pectoral` 为 **拼装件**，同样需人工统一比例后再绑骨或父子节点。

## 6. Palette JSON 与 palette-swap 如何读

每线两个文件（路径：`Assets/Watercolor/{Line}/Palette/`）：

| 文件 | Asset ID | 内容 |
|---|---|---|
| `{line}_pal_main.json` | `{line}_pal_main` | 主色字典或 `colors` 数组（hex + role/中文名） |
| `{line}_pal_swap_cfg.json` | `{line}_pal_swap_cfg` | 命名 swap 模式：`sat` / `warm` / `tint` / `glow` 等 |

**读法**

1. `JSONSerialization` / `Codable` 解析。
2. 校验 `style_board == "SB-2026-11-07-v1"`（不一致则拒绝静默混用）。
3. `main` → UI 强调色、粒子色、雾色默认值。
4. `swap_cfg` → 关卡状态机切换（如雁 `polluted`、鲸 `turbid`、鹿 `mine_dust`）。
5. 用 `SKShader`（GLSL ES）或 `color`/`colorBlendFactor` 做克制染色；**禁止**用警报红表示危险。

Goose swap 示例键：`normal` · `polluted`。  
Whale：`normal` · `turbid` · `port_night` · `clear_upwell`。  
Deer：`normal` · `mine_dust` · `false_spring` · `night_lights` · `regreen`。

字段名在三线 JSON 中略有出入（`sat` vs `saturation`）；agent 应按实际键读取并做兼容，**不要**改写源 JSON 除非任务要求。

```swift
// 伪代码
struct PalSwapMode: Codable {
    var sat: Double?
    var saturation: Double?
    var warm: Double?
    var tint: String?       // "#RRGGBB"
    var tint_hex: String?
    var glow: String?
    var note: String?
    var description: String?
}
```

## 7. 后处理现状与临时透明处理

### 现状（事实）

- 绝大多数 PNG 由 **JPG 转存**，扩展名为 `.png`。
- **暂无有效透明区域**（部分 RGBA 文件的 alpha 全不透明）；背景多为浅奶油/浅纸色（约 `#F5F0E6` 一带）。
- **尚未**统一抠透；台账验收默认：「生成初稿；待人工抠透与统一色」。
- 部分图可能含 style_board **烧录小字**，需擦除。
- 本文 **不声称**已做抠透明，也 **不提供**性能帧率数字。

### Agent 临时处理（仅开发预览）

1. **色键（chroma key）**：对接近纸色的像素降 alpha（阈值色 + 容差）；仅用于编辑器预览，不代替最终抠图。
2. **手动 alpha 备注**：在节点旁注释 `// needs cutout; source has opaque paper bg`。
3. **SKSpriteNode**：临时可用 `.alpha` blend + 略抬 `zPosition`；避免把未抠透角色当遮罩源。
4. **正式入库**：人工或专用管线抠透 → 再进 `Assets.xcassets` / `@2x` `@3x`。

不要把色键结果当作最终美术提交。

## 8. 推荐接入步骤（分步）

按顺序做；每步可运行再进入下一步。

### Step 0 — 索引

- 从 `Assets/docs/asset-index.json` 按 ID 选取当前 active 计划需要的候选；不将整个素材库复制到工程资源组。
- 保留原稿 ID；许可确认、人工清理 / 统一色调与验收后，再导出正式资源并登记映射。

### Step 1 — Graybox

- 用色块/`Assets/Graybox`（若有）搭三段迁徙滚动与碰撞。
- 主角用矩形占位，先跑通输入与段切换。

### Step 2 — 换 Watercolor 视差

- 选当前线当前 `seg`，加载六层 `*_scene_{seg}_{layer}`。
- 配置 v0–v3（及 fog/water）系数；确认 tile/回绕策略。
- **不要**在 mid 纹理上画 Trace。

### Step 3 — 主角循环

- 雁：先 FLY `fly_side_01…08`；再接 TAKEOFF/LAND。
- 鲸：先拼 `body`+`tail`+`pectoral`，再加 BREACH/REST/calf。
- 鹿：先 WALK，再 RUN/FORAGE/REST。
- 设置锚点（§2.4）；注释未对齐风险。

### Step 4 — Trace overlay

- 按关卡表挂 `*_trace_*` 为独立节点；淡入淡出或 parallax 跟 mid/near 之间。
- 遵守禁止项（无缠网特写、无品牌、无车祸）。

### Step 5 — UI 信物

- 雁羽毛 / 鲸骨笛 / 鹿角：`normal` + `pressed` texture 切换。
- 可用 `*_ui_stroke_*` 作按钮底或转场笔触。

### Step 6 — VFX 粒子

- 将 `*_fx_*` 与 `shr_particle_*` / `shr_glow_soft_*` 赋给 `SKEmitterNode.particleTexture` 或短动画节点。
- 未抠透前降低粒子 alpha，避免纸色方块闪烁。

### Step 7 — Palette-swap

- 读 `*_pal_swap_cfg.json`，在污染/矿尘/夜港等状态切换 tint（§6）。

## 9. 已知限制与「不要做」清单

### 已知限制

| 项 | 说明 |
|---|---|
| 无音频 | `Audio/Creatures|Music|SFX` 为空占位 |
| 无触觉 | `Haptics/` 为空占位 |
| 无有效透明区域 | JPG→PNG，含全不透明 RGBA；待抠透 |
| 循环未对齐 | FLY/WALK/RUN/BREACH/TAKEOFF/LAND 等均需后处理 |
| 视差非无缝 | 同段色温大致统一，接缝与地平线需人工 |
| Trace 初稿 | 部分偏「整景」，需裁成纯 overlay |
| 许可 | Grok Imagine **待确认** |
| 数量 | 以台账为准；Goose 完整线约 90+（含 Shared） |

### 不要做

1. 不要编造或引用不存在的音频/触觉文件。
2. 不要声称已抠透明或给出未经测量的 FPS/内存数字。
3. 不要把 Trace 烤进 `mid`/`near`。
4. 不要用警报红、血腥、品牌、车祸、缠网特写。
5. 不要混用非 `SB-2026-11-07-v1` 风格资产而不改台账。
6. 不要在未对齐帧上当作最终动画交付。
7. 不要重命名文件导致 Asset ID 与台账脱节（若必须改名，同步改台账）。
8. 不要在许可核实前用于正式对外商店包。
