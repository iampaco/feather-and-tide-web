# 如何合并分卷（历史归档恢复）

> 当前项目指定素材库已归并到 `Assets/`，见 [素材库入口](../README.md)。以下命令只说明原始分卷的恢复方法，不是当前目录结构；请在项目外的新空目录解压，避免重复导入或覆盖当前文件。

Drive 上三个文件：

- `羽与潮-游戏素材包.tar.gz.part00`
- `羽与潮-游戏素材包.tar.gz.part01`
- `羽与潮-游戏素材包.tar.gz.part02`

在终端（macOS / Linux）：

```bash
cat 羽与潮-游戏素材包.tar.gz.part00 \
    羽与潮-游戏素材包.tar.gz.part01 \
    羽与潮-游戏素材包.tar.gz.part02 \
  > 羽与潮-游戏素材包.tar.gz
tar -xzf 羽与潮-游戏素材包.tar.gz
```

历史归档解压后进入原包目录阅读随包说明。当前项目请直接阅读 `Assets/README.md` 与 `Assets/docs/素材说明与接入指南.md`；原包到现目录的映射见 [迁移清单](library-migration-2026-11-08.json)。
