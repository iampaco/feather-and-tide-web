# 《羽与潮》鲸章节执行计划 · 安静航道

**P2 原型 W0–W4 已可游玩。** 交付一张连续的 W0–W4 地图，用于仅旅程流程。玩家用双手带领 1+5 只鲸，从近岸海湾穿过船道、渔网和噪声带，最后在外海以 6/6 浮出水面汇合。首轮用约 4–6 分钟、两处检查点搭建灰盒，章长和操作参数按试玩调整。原型使用开发入口；正式解锁按 GDD 的雁十年线条件验收。

查看[俯视布局](layout.md)及[执行记录、回放与截图](04-execution-record.md)。真机和首次玩家验收按[真机试玩单](05-real-device-handoff.md)记录。

制作顺序沿用斑头雁的做法。先在安全区证明手感，再用最难读的危险验证规则；灰盒可通关后，用原回放对照水彩素材版。[斑头雁执行计划](../goose/execution/README.md) · [GDD v2.0 §6.3、§10、§12.3](../../../Feather_Tide_Gameplay_Design_v2.0.md) · [TDD v1.0 §8.1](../../../Feather_Tide_Threejs_TDD_v1.0.md)

## 并行开发与合入顺序

| 顺序            | 鲸章节开发                                                                     | 共享接口及雁线回归                                                                                                          |
| --------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 1 · 建立基线    | 画 W0–W4 顶视布局；准备单船和全深网的几何样例；检查候选鲸 GLB 的轴向、海面尺度 | 当前工作区的 `main` 尚无首个提交。实施前确认可纳入基线的现有文件，保存雁回放和旧存档夹具，再从共同基线开独立分支与 worktree |
| 2 · 先通 W0／W1 | W0 做六鲸、三层和双手。W1 用同一份数据证明船影、分层碰撞和换气窗口             | 共享契约由一名负责人维护，先接入运行时、关卡和表现接口。雁线复跑结阵、输入、路线与 12/12 落脚                               |
| 3 · 接成整章    | W2 网口与救援、W3 双路、W4 汇合；从整个航程接上 C1、C2                         | 接入独立存档槽位、快照校验与恢复。交替完成雁和鲸的旅程，验证继续及历史结果对应正确章节，并验证旧漫游槽隔离                  |
| 4 · 接入素材    | 用现有鲸资产与音乐做一段 W0／W1 音画样段，复核后扩到 W2–W4                     | 同版对照灰盒回放，复测低画质、静音、后台恢复与目标机性能                                                                    |

W0／W1 灰盒与资产评审可并行；共享状态、关卡 Schema、输入与存档的接口变更由对应负责人先合入，再接调用方。认领时登记实际负责人、依赖提交、预计交付与验收编号。

## 试玩后确认的决策

| 决策                   | 首轮做法                                                                   | 判据                                                             |
| ---------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 镜头相对方向与观察范围 | 复用 ADR-009 的 A/B 比较；从可看清海面层和队尾的受控斜俯视开始             | 等船、下潜及回望时的误转、离线距离、复位和恢复航向用时           |
| 下潜与队伍错层         | 约 1 秒进入浅潜、再约 2 秒到深潜作为初值；让同伴依次响应，有各自的实际水层 | 观察到队尾的风险也能预判；低呼吸和上浮预警留出操作余量           |
| W2 接应编排            | 先准备可复现的单同伴救援场景，再试玩风险触发或固定教学触发                 | 玩家理解离队原因，绕行空间够用，两手可独立折返接应               |
| 章节节奏               | W1 后可停留换气，W2 后有舒展航段，W3 后有安全汇合水域                      | 记录首次玩家用时、犹豫处、呼吸余量和停留意愿，更新参数与设计记录 |

共享输入依据 [ADR-009 原型提案](../../adr/009-dual-hand-camera-controls.md)。鲸篇原型已接入 `WL-CHR-001` 与《Deep Blue Drones》。鲸模型保留待美术审核状态，资产来源及授权记录分别见清单。[鲸模型清单](../../../Assets/Watercolor/Whale/Blender/WL-CHR-001/v001/asset_manifest.json) · [Web 资产清单](../../../public/assets/manifest.json)
