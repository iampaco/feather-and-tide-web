## 回放取点

以下为常用航路坐标。实际回放以逐 tick 输入、快照与事件为准。

### 海湾起游

- 从 `(0, 48)` 可顺水面航标直游遇到 `bay-shoal (5, 118)`，也可经 `bay-bend-entry (-19, 74)` 向 `bay-turn (-33, 105)` 缓转，再松手滑向内湾静水。在湾内任意安全水面都能停驻、浅潜和上浮。直线与内湾线均连到 `bay-exit (0, 248)`。
- 经过银鱼后向 `(21, 145)` 对准，浅潜后沿 `+Z` 推进。出流再向西缓转、上浮，亮水可换气等队尾。领鲸越过 `z=218` 可观察湾外货船的实时方向。
- 越过 `z=270` 到 W1 待航水域。出湾前后沿同一条水面箭头接至 `ship-wait (0, 340)`。W1 船道预警仍从 `z=357` 开始。

### 船道

- 水面等船可在 `x=0, z≈372` 收速，保持水面。船在第 `3600` tick 左右从东向西通过 `x=0`。领鲸抵达待航水域的时相取决于此前的输入。观察船尾离开并确认水面空档，再保持 `+Z` 穿越，向 C1 游动。
- 深潜穿越沿 `x=0` 从 `z≈373` 按住能力，保持同一方向直到领鲸约 `z=455`，观察队尾越过船后再松开。约 12 秒的按住区间包含约 3 秒的初始下潜，留出深潜呼吸余量。全队上浮后可在 C1 保存。
- 船初始轮廓在 `x=-136–-106, z=408–428`，横向往返 242 单位，每 6000 tick 一个周期，初始相位 900 tick。两端对称收尖，船体轮廓随位移平移，船头提示随运动方向调整。
- 双条琥珀虚线标明 `z=408、428` 的巡逻水带。领鲸沿 `x≈0` 从待航区通过时，可据船头、尾迹和水面空档提示起游。到达船后 `z=459` 的静水后沿箭头向 C1 内游，直到全队在水面入区。
- 以 9.2 单位/秒巡航、碰撞半径 1.7 单位计算，从预警区前缘到理论最早接触约 5.36 秒。默认镜头可在待航水域看到预警，浏览器反应窗口另见[执行记录](04-execution-record.md)。

### 网口与选路

- C1 保存后先看到短口与宽线预告，再分别向 `net-short-entry (75, 705)` 与 `net-wide-entry (114, 708)` 游动。短线沿 `x≈75` 提前对准后缓游，外侧宽线沿 `x≈124` 巡航并进入网外静水。领鲸接近网的远侧且前方净空时，画面标记实际还没清网的队尾和可继续直游的位置。
- 无网水道以成对浮标标明外侧宽线，回收码头位于东侧可游边界之外。网外可沿原有海藻湾缓弧进入补给区。
- 固定步擦网样例从 C1 依次向 `(0, 567)`、`(5, 672)`、`(70, 709)`、`(33, 828)` 加速。过早切向西方会把同伴留在南侧网边。折返可经 `(75, 806)`、`(75, 737)` 绕到南侧，接近同伴后减速同层接应。回程沿 `x≈124` 宽线带回全队。
- 近航道从 `(62, 1083)` 看噪声空档，或进 `(112, 1072)` 的静水湾等待。穿越后到 `(74, 1151)` 一带换气与补给，再向汇流航标前进。
- 近航道出噪声带后预告疏浚水域。水面浮标从 `(69,1174)` 开始，清水边线从 `(27,1174)` 开始，可在清水边浅潜。两线通向 `dredge-rest`，鲸群可在 `(66,1265)` 一带上浮集队，之后去汇流处。
- 安静航道的水面宽线沿 `quiet-mid (-82, 1114)`、`quiet-arc (-109, 1165)`、`quiet-bend (-102, 1218)` 绕浅礁。借流线在水下先沿流向 `(22, 50)`，再向较偏东的 `(44, 29)` 转。两段之间可在 `current-eddy (-68, 1206)` 上浮等队尾。鱼群和光斑集中在东侧静水，三种走法均通往 C2。
- 两个入口共用 `x=-36` 的边。锁定前可回到 `z<1040` 并重选。C1 位于分岔前，C2 位于汇流后。

### 外海

- C2 保存后，在 `(61,1395)` 附近预告防波堤横流。短线在堤头东侧，横流最高以每秒 3.1 世界单位向 `+X` 推动区内鲸群，进入和离开时渐变。可朝来流略偏航。宽线入口 `(94,1422)` 在横流之外，可沿水面直游或浅潜借流。前方静水接应点为 `(65,1470)`。
- 观鲸船减速区由 `watching-rest` 定义，`x=67–126, z=1463–1516`。船只在 `x>142` 巡回，鲸群可以走内侧、停留换气或沿航标继续。显示区内已经上浮的鲸数，终点依旧从 `z=1518` 开始。
- 从 `z=1461` 起允许在亮水中停留换气。通过 `surface-here (63,1476)` 后，箭头指向 `offshore-marker (79,1552)`。汇合入口的两段亮标贴在目标区前沿 `z=1518`。
- 常用入区线在 `x≈65–80`。领鲸先到可在区内停稳，转镜查看标出的区外同伴。浅潜入区时先上浮换气，若尚有同伴未就绪，可查看其水层或上浮方向。
