# 02 · W0–W4 灰盒制作单

旅程各段使用同一个连续 XZ 世界。先配置入口、出口、可游水域、危险轮廓与安全区，再加提示、事件和外观。每张卡交付地图修订号、俯视配置图、默认视角截图、世界输入回放及预期事件；危险段另交付转镜与低画质画面。共享依赖见 [01 · 鲸原型共享接口](01-shared-contracts.md)，验收编号见 [03 · 验收与试玩](03-verification-and-playtest.md)。

| 路段  | 玩家取舍                         | 出口或汇合条件                         | 依赖                                 |
| ----- | -------------------------------- | -------------------------------------- | ------------------------------------ |
| WH-W0 | 提前转向、停稳观察、浅潜后换气   | 玩家带队越过海湾航标，进入 W1 预警水域 | C01、C02 基础数据、C03               |
| WH-W1 | 减速等船，或择时深潜并留余量上浮 | 船道外的安全水域与 C1，全队可停留换气  | W0、C02、C04；C05 接续航             |
| WH-W2 | 找到真实网口，必要时折返接应     | 从网外安全侧带队通过出口               | W1 的深度几何、C04、C05 中的 C1 恢复 |
| WH-W3 | 走近而嘈杂或远而安静的水路       | 两路在安全区汇合，锁定线路并触发 C2    | C02 路线数据、C04、C05               |
| WH-W4 | 减速等队尾、让全队浮出水面       | 6/6 就绪后短汇合演出及一次结算         | C03、C04、C05                        |

## W0 · 海湾起游

**交付 WH-W0。** 一个可从开发入口复测的安全实验场，从单鲸转向调参扩到六鲸连续操控。

- [ ] **搭建。** 放置开阔海湾、远处出口航标、侧向观察地标与宽弯。根据加速松手后的实测滑行距离预留回旋空间；海湾有充足水面换气区。
- [ ] **编排。** 在首次推进、松手、拖镜、复位和浅潜上浮时给短提示。教学结束以操作反馈收束，玩家可跳过提示并主动前往出口。用海面／浅潜／深潜标签及呼吸变化解释每次浮潜。
- [ ] **验收。** 键鼠和真实横屏触控各完成移动＋拖镜及移动＋下潜。覆盖缓行、巡航、加速、逆向输入、松手停稳、六鲸队尾错层、手动上浮和耗尽上浮。在安全水域按住直到耗尽并完成换气，模拟继续正常进行。录制 A/B 相同航线，测停稳距离、转向和恢复航向。对应 WH-A01～A03。

## W1 · 单船航线与检查点 1

**交付 WH-W1。** 一艘固定周期船、两种可行的穿越方案、下游安全换气区和 C1。

- [ ] **搭建。** 在碰撞前布置清楚的船影、航向箭头、尾迹和占用层提示。船道前提供足够减速的待航水域，船道外留出接纳 6 只鲸的换气空间。顶视图标明船轮廓、警告触发位置、预计下潜点、可上浮区和 C1。
- [ ] **编排。** 以水面／浅潜受船影响、深潜可穿越作为首轮样例；保留等船经过再水面航行的路线。低呼吸提示引导朝安全水域移动，领队先穿过时提示队尾仍可能在船的作用层。C1 于全队进入安全水域后保存，玩家可在此等待换气、转镜再离开。
- [ ] **验收。** 从可复现的船相位分别录制水面等待与深潜通过、过早上浮、尾鲸仍在浅潜、耗尽上浮及贴边接触。用默认镜头从首次能辨认风险到预计接触测量反应窗口，目标至少约 3 秒巡航，含松手惯性；再用侧视与回望检查前方提示。以低呼吸、可执行的减速／转向输入证明有安全换气路径；从同一 W1 起点快照重放可复现船的接触时机，回 C1 后船相位与保存的 tick 相符。对应 WH-A03～A05、A08。

## W2 · 渔网区

**交付 WH-W2。** 全深网与真实缺口、一条完整绕行回放、一个可复现的单同伴接应场景。

- [ ] **搭建。** 用浮标和按层可见的网线表示网具占用，外侧设置明确的无网通道。按鲸群实际转弯半径和队尾轨迹定缺口宽度。网外开阔侧为接应位置，留出折返回转空间。
- [ ] **编排。** 旅程先验证一次单同伴离队及归队流程；用可复现的接触条件或单独教学夹具建立事件。显示同伴所在方向、深度、接近／缓行提示和计时，归队后给舒展水域。沿外侧航标可以绕开该演示。
- [ ] **验收。** 三层沿网直行均遇相同 XZ 阻挡，三层沿真实缺口均能通过。对照极限俯角、回望、静音和低画质下的网口。旅程给出正确接应、错层、超速、暂停和超时回 C1 的回放；从默认镜头依方向提示也能接回。保留两类完整回放，分别覆盖绕行与主动接应。对应 WH-A04～A06、A08。

## W3 · 噪声带与安静航道

**交付 WH-W3。** 入口可比较的短线与长线、跨层凝聚压力、路线记录及 C2。

- [ ] **搭建。** 在选择前就能看到两路入口、去向和各自线索。短线用船道边界、波纹和文字提示噪声，长线用连续航标和开阔水面标出安静水路。两路各有可达换气区，低能量时可抵达安全水域或补给，汇入同一通向外海的水域。
- [ ] **编排。** 按实际跨越入口记录路线，汇合后锁定，C2 写入路线及当时的世界相位。短线噪声使凝聚下降，深潜仍可感知；长线以更多航程换取稳定跟随。退出噪声带后留出可停留的缓和段。
- [ ] **验收。** 在同一起点比较两路的耗时、能量、凝聚及队尾间距。验证贴边和往返穿越时的路线事件，回 C1 可重选，恢复 C2 保留已选路线。旅程各走两条完整航路，静音仍能解释选路依据。对应 WH-A07～A09、A11。

## W4 · 外海汇合

**交付 WH-W4。** 容纳全队上浮的终点、真实到达人数及可复测的一次结算。

- [ ] **搭建。** 标出外海目标轮廓、上浮提示和等待水域。默认镜头展示入口与水面状态，汇合演出使用能看见 6 只鲸的舒展构图。
- [ ] **编排。** 领队先到显示实际人数和等待原因，例如队尾在区外或仍在上浮。最后一名成员完成上浮且满足汇合谓词后锁定模拟，播放短音画收束。建议沿用雁线，在进入演出时写入模式、路线和抵达结果，结束或跳过后展示保存状态。
- [ ] **验收。** 覆盖 5/6、六鲸 XZ 都在目标内但一只仍在浅潜、过渡未完、待救援、正在归队和 6/6。断言 HUD 与胜利使用同一结果；同 tick 满足汇合时，进入演出并冻结失败与资源更新。连续点击跳过或转屏仅产生一次结算，保存成功后刷新或返回标题可载入该结果。对应 WH-A08、A10、A11。
