# M3 · S0–S6 连续关卡灰盒

玩家从晨雾湿地起飞，经顺风带抵达检查点 A，再选山口或长湖。两路在河谷汇合，随后经历一次教学救援、风电外围、逆风和最终落脚。段落由数据与触发器串联。轨迹、风、Zone 和相位通过同一世界状态延续，旅程与漫游使用同一份地图。

```text
S0 晨雾湿地 → S1 顺风带 → A 检查点
                            ├─ S2 短山口 ─┐
                            └─ S2 长湖路 ─┴─ S3 河谷救援 → S4 风电外围 → S5 逆风 → S6 落脚
```

| 段落               | 玩家面临的决定                                     | 配置与验收                                                                                                                                                                         |
| ------------------ | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **S0 晨雾湿地**    | 起飞、轻推转向，试用拖镜和复位，松手体验滑翔       | 安全区、雾线、方向地标、短提示。镜头教学可跳过，玩家可继续在安全空间尝试。全队升空并通过雾线才离开                                                                                 |
| **S1 顺风带**      | 直线结阵省力，接近弯道提前解除                     | 风向可读，宽容弯道展示机动性代价。急转导致队形松散但有恢复空间。全队通过 A 时保存包含补给状态的快照，此时仍可自由选路                                                              |
| **S2 山口 / 长湖** | 选近而风急的山口，或选更远、队形更稳且能补给的长湖 | A 附近能辨认两个入口及线索，转镜可提供更多信息。满能量可过山口，长湖不补给也能到汇合处。两互斥提交区及汇合锁定记录路线，边界重复经过不刷记录                                       |
| **S3 侧风救援**    | 识别队尾离队，减速、转身、缓行接应                 | 风痕/树梢先预告。固定事件可重放，接应圈在开阔可达处。旅程初值约 40 秒，接应约 2 秒，实际折返留足余量。漫游无倒计时并逐步自动归队；默认视角与静音也能定位                           |
| **S4 风电外围**    | 提前辨认外侧走廊，决定解除结阵和是否去保护湿地     | 使用同一连续轮廓显示与判定叶轮扫掠区，叶片转角不产生可钻空隙。默认视角有效预警约 3 秒巡航反应窗口，考虑滑翔距离与转镜注意力。原型按完整 V 形宽度约两倍起测，验证真实通路与补给支线 |
| **S5 逆风归途**    | 在能量、速度和结阵之间取舍，决定是否补给           | 用可见风向和队尾变化解释消耗。枚举低能量触发位置，确认可达补给或安全地。用 S5 失败重试录像评估是否需要第二检查点                                                                   |
| **S6 芦苇落脚**    | 降速进入终点，等同伴全部抵达                       | 验证 `11/12` 的等待提示、最后一只仍离队、全员进入、落脚锁定和演出结束。落脚完成后只记录一次模式与路线                                                                              |

## 制作顺序

1. **L01 / L02** 定义连续 XZ 地图、通路宽度与段落入口出口。先跑 S0–S1 和 A，再接两条完整 S2 回放。用地标、轮廓和纯色区验证两路一眼可辨及绕行所需空间。
2. **L03** 接 S3 固定预警与归队触发器，再接 S4 预警、外侧通路和湿地。调试视图同时显示扫掠区、队形占地、预计反应时间、救援可达区域以及当前相位。
3. **L04** 完成 S5 低能量补救和 S6 全员落脚。连接模式选择、暂停、失败重试和结果界面。以首次玩家录像检查开阔段、保护湿地和落脚是否提供舒展空间。

## 阶段出口

- 保存旅程山口、旅程长湖、漫游山口、漫游长湖四条完整回放。两条旅程失败路径均能从 A 重试，恢复相同世界相位且可重新选路。另保存一条默认镜头与静音通关记录。
- 完成首次玩家横屏试玩。记录岔路在何处被理解、S3 真实接应时间、S4 在默认/转镜时的可见反应窗口、S5 补给可达性、S6 等队与全员抵达。GDD 的约 3–5 分钟是待验证目标，记录实际路线时长与分段节奏。
- 提供灰盒顶视图、默认镜头图、段落出口条件与可复现输入。更换某段视觉后复用该段回放和可读性测量。
