# M2 · 规则闭环与检查点

将飞行实验场扩成一张小型测试地图，包含风带、可见危险、补给、安全地、一次可复现救援、检查点与终点。同一地图在 `ModeRules` 下运行旅程和漫游。地图出口通过后进入正式 S0–S6 灰盒制作。

| 任务                     | 工作与责任边界                                                                                                                                                     | 验收                                                                                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S04 能量、凝聚与模式策略 | 由模拟根据巡航/加速、风、急转与结阵更新能量和凝聚。旅程使用资源与失败规则，漫游保留操作和轻度疲劳反馈，危险为无损失软阻挡                                          | 初值低能量约 30% 提示补给方向、约 15% 限速。旅程能量为零且在安全/补给区外才因此失败。漫游反复接触危险不损耗、不计时、不判失败，不被推入不可达区域                             |
| S05 七类 Zone 与碰撞     | 定义 `Warning`、`Hazard`、`Interference`、`Supply`、`Sanctuary`、`Checkpoint`、`Goal` 的判别字段及触发对象。用连续 XZ 几何检查防高速穿透。给渲染输出同一轮廓       | 校验闭合轮廓、无自交、有效面积与引用。运行时验证危险内外、高速跨边、边界接触及漫游软阻挡。预警与碰撞有可测距离。干扰影响能耗/凝聚，本身不触发离队                             |
| S06 队员状态与救援       | 稳定 ID 对应 `following`、`loose`、`strayed`、`rejoining`。通过可达接应圈缓行且保持初值约 2 秒触发归队。旅程每个离队者用同一模拟时钟独立计时，教学只引入一只队尾雁 | 离队者保留在名单上并有明确指示，能主动折返接应。旅程任一时限归零触发重试。漫游无倒计时、可逐步自动归队。暂停和后台期间剩余时间不变                                            |
| S07 补给、保存与恢复     | 领队和多数队员进入补给范围按配置进入休整。全队通过检查点后建立完整快照，持久化采用版本化 IndexedDB 记录。App 从内存或最近已落盘检查点恢复                          | 反复进出不能刷容量。快照恢复每只雁、能量/凝聚/队形、救援、补给、模拟 tick、世界相位、触发器和已选路线。重试时应用原型满能量规则。检查未落盘、损坏和版本不匹配的提示与恢复路径 |
| S08 落脚与结算           | 共享 `Goal` 到达谓词供模拟与 HUD 使用。进入落脚阶段后锁定失败判断、玩法输入与模拟计时。完成后发出一次结算事件                                                      | 领队先达显示等待，11/12 或仍有待救援者均不结算，12/12 才开始落脚。落脚期间不能返转成失败，结束或跳过演出均只结算一次                                                          |

状态/事件、资源、相位、路线与关卡版本都受到同一固定 tick 约束。诊断视图显示 tick、队员状态、触发区、能量、凝聚、相机意图及碰撞轮廓，方便复测。

## 阶段出口

- 至少为正常抵达、能量耗尽重试、救援超时重试和漫游软阻挡后抵达各留一条可复现路径。另测旅程救援成功、安全区内能量为零、未齐队与落脚的边界。
- 比较保存和恢复结果，单列预期变化如重试能量回满。读档后不得重发已触发的一次性事件或重复结算。暂停后继续必须显式触发，救援与世界相位冻结证据同时保存。
- 一份版本化地图样例通过运行时与 CI 校验，规则测试不依赖 Three.js、浏览器和资源加载。
