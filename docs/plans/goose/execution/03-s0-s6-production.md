# 03 · S0–S6 场景制作单

**依赖。** M2 的小地图已验证规则闭环。以下每段都能用 Three.js 灰盒完成试飞。随后依据 [该段的建模组合](04-modeling-and-assets.md)接入正式画面，并用原有回放复测。各段保持在同一 XZ 世界，A 位于分岔前。场景分区加载时，玩家仍保持连续操控。

| 工作包         | 交付顺序                                            | 关键结果                                                           |
| -------------- | --------------------------------------------------- | ------------------------------------------------------------------ |
| L01 世界布局   | 入口/出口与段落交界、地标、风场、可达区、触发器命名 | 一个可以从 S0 走通至 S6 的开发版地图，旅程和漫游读取同一配置       |
| L02 教学与双路 | S0、S1、A、S2 两路                                  | 记录基础操作和选路时机，A 重试允许重选，两路各有动机和出口         |
| L03 救援与风场 | S3、S4                                              | 固定队尾救援可重放，风机边界多角度同源可读，外围允许实际通过与补给 |
| L04 返航与落脚 | S5、S6、菜单和结算接线                              | 低能量可补救、完整 12/12 才落脚，四种路线/模式组合通关             |

每段提交 `levelRevision`、顶视配置截图、默认视角截图、事件顺序、实际输入回放、从何处开始复测，以及对应的美术资源 ID。场景配置保存玩法轮廓，视觉材质和固定相机的审阅模型可由资产清单替换。

## S0 · 晨雾湿地

- [ ] **搭建。** 定出生队形、开阔训练水域、明亮前进地标和雾线。让低速盘旋的范围仍处于相对安全空间，玩家可看到队尾和湖岸。
- [ ] **编排。** 有效推动才起飞，在安全水域用短提示引导移动、松手滑翔、拖镜和复位。提示在动作完成后退场，镜头教学可跳过。全队升空并越过雾线后退出 S0。
- [ ] **验收。** 首次玩家能辨认前进方向并靠操作理解松手惯性。测试从队尾观察后复位、停下来学习、跳过提示和直接越线时的全队判断。S0 的硬危险与救援计时应为空。

## S1 · 顺风带与检查点 A

- [ ] **搭建。** 放置偏离主航线的可读风痕、适合成阵的直段、宽容的弯和芦苇洲休整处。让弯道在玩家仍按住能力时可识别。
- [ ] **编排。** 用 V 形逐步收拢和翼声变化提示形成度，急转表现队伍拉长。弯前释阵有明显收益。A 采用全队触发并保存补给、队伍与世界相位。
- [ ] **验收。** 同速比较直线的结阵能耗和弯道的回转表现，玩家可只用两手完成观察、释阵再转向。检查存档从何时生成，A 附近能够安全观察 S2。

## S2 · 短山口与长湖

- [ ] **搭建。** 让两个入口从 A 附近都可识别。山口用侧风、树线和山形突出短而急，湖路用岸线、开阔水面和可见补给突出长而稳。
- [ ] **编排。** 使用互斥的 route-commit 区和河谷汇合区。记录玩家选择，汇合时锁定本次路线。验证返回边界和 A 重试不会重复记录。
- [ ] **验收。** 满能量山口可通过且不会在必经点脚本离队。长湖按预期初值无需补给可达汇合，考虑用低能量反馈体现距离。让首次玩家在进入分岔前说出两路的区别。分别保存两模式两路线的完整输入。

## S3 · 侧风与照顾队尾

- [ ] **搭建。** 河谷先出现斜风痕与树梢摆动，接应点位于可看见或可通过方向提示找到的开阔芦苇水域。确认领队有折返及重新切入主路的空间。
- [ ] **编排。** 固定触发点与队尾 ID，触发一次，旅程出现约 40 秒提示。靠近后缓行约 2 秒，归队时给出清晰的动作、呼应与音乐释放。漫游保留侧风及跟随表现并逐渐归队。
- [ ] **验收。** 分别记录经右手回看和仅看边缘箭头的接应路线。测试错误方向、太快穿过、暂停、超时回 A、从另一条 S2 路线再进 S3。区分系统参考路径耗时与玩家实际耗时。

## S4 · 风电外围与保护湿地

- [ ] **搭建。** 弧形安排风机姿态与外侧走廊，先放同源连续扫掠轮廓和外侧湿地补给。把地形、塔架、风压线和雾放入同一默认构图检查层级。
- [ ] **编排。** 预警先于接触，姿态变化保留同一判定。主动回看时有前方方向提示。旅程接触才产生成本，漫游软阻挡后可顺势从外围离开。让走廊在继续满阵和解阵绕行的试玩里都能用真实队形测量。
- [ ] **验收。** 在默认视角、左右偏航、最高/最低俯角及小屏上按实际巡航测量从首次可辨预警到逻辑接触的间隔，目标至少约 3 秒并考虑松手滑翔。顶视逐段比对几何与风压边界，在轮廓接缝、高速穿越及叶片不同相位下做断言。量测完整 V 形宽度与走廊余量，记录绕行、补给和离场的回放。

## S5 · 逆风归途

- [ ] **搭建。** 风痕指向逆风，保留能辨方向的终点地标。设置可从低能量位置抵达的补给或安全水域。将补救路线和上一段是否使用湿地一起纳入测试。
- [ ] **编排。** 让速度和队尾拉长解释能量压力，直段支持结阵渡过逆风。低能量提示给出明确补给方向，缓行或休整后反馈恢复。
- [ ] **验收。** 从两种 S2 路径、S4 选择与不同能量进入，按巡航/结阵/补给验证可达性。记录 A 重试到 S5 的实际用时和再次尝试意愿，供是否增加 B 的评审使用。

## S6 · 芦苇落脚

- [ ] **搭建。** 终点留足整群进入与降速空间，航线上清楚区分通行水面与芦苇。准备可展示全体同伴的落脚构图。
- [ ] **编排。** 领队先达显示等待和当前人数。全员符合条件后锁定玩法，进入短落脚演出，音乐完整收束并提供继续/跳过。结果记录模式、路线和目的地。
- [ ] **验收。** 测队尾停在边界、仍在离队、全员刚进入、暂停恢复、跳过和返回菜单。验证多次点击或恢复不会重复完成。询问首次玩家是否理解为什么需要等，以及是否感到全队一起抵达。
