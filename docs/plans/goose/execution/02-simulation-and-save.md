# 02 · 玩法规则、区块与存档

**阶段交付**为一张可从正常入口运行的小地图。玩家能在一轮里体验风、结阵、补给、危险、救援、失败重试和全员落脚。先用可见几何制作验证场，规则通过后将系统用于正式 S0–S6。

## S04 · 能量、凝聚与模式规则

**依赖与产物。** E02、S02、S03。交付一份调参配置、`ModeRules`、状态事件和纯逻辑测试。

- [ ] 分别测试缓行/巡航/加速、顺逆风、急转、阵型各自对能量和凝聚的影响。记录低能量约 30% 指示和约 15% 加速限制从哪一 tick 开始，以及恢复后何时撤销提示。
- [ ] 同一地图校验旅程只有能量归零且在安全/补给区域外，或者任一离队者超时可失败。接触危险按风险规则处理。漫游保留观感和主动移动，危险只有无损失软阻挡、无失败及无救援压力倒计时。
- [ ] 加入边界测试。能量恰为零进入安全区、离开安全区能量仍为零、两种模式重复接触同一危险、在安全区保持停留与观察。输出能量曲线供 S5 调整补给距离。

## S05 · 七类 Zone 与几何校验

**依赖与产物。** E03、S04。交付可判别联合类型、XZ 几何、区域进入/退出事件和轮廓调试渲染。

- [ ] 实现 `Warning`、`Hazard`、`Interference`、`Supply`、`Sanctuary`、`Checkpoint`、`Goal` 的触发对象与配置语义。对领队、任意成员、多数成员、全队的判定建立夹具，保留离队成员 ID。
- [ ] CI 校验轮廓闭合、非零面积、无自交及引用有效。碰撞从前位置到当前位置连续检查，覆盖高速越界、擦边、并集接缝、软阻挡滑出。用同一 `zoneId` 及轮廓数据渲染范围，视频记录与调试轮廓叠加检查。
- [ ] 补给记录实体容量。对队员不足、容量耗尽、反复进入、结阵期间补给与恢复快照进行测试。干扰作用从配置进入统一系统。

## S06 · 离队与主动接应

**依赖与产物。** S02、S04、S05。交付队员状态机、接应进度、方向提示数据和可复现的救援夹具。

- [ ] 保持 `following`、`loose`、`strayed`、`rejoining` 的稳定 ID，等待者留在可达位置。旅程为每个离队者用 tick 计时，进入接应圈保持缓行约 2 秒后逐渐归队。定义离开接应圈时进度的规则并在测试里固定。
- [ ] 教学触发绑定稳定队尾 ID、可读固定侧风和可达标记。验证接应达成、太快穿圈、提前离开、最后一 tick 的接应和超时边界、多个独立计时的暂停与恢复。漫游从相同风场表现进入缓慢自动归队。
- [ ] 输出能同时支持世界标记、屏幕边缘箭头、带静音等价提示的救援事件。M3 测量先发现、折返、接近、接应四段耗时，比较约 40 秒时限与约 10–15 秒参考路径，保留首次玩家实际余量。

## S07 · 检查点、重试与存档恢复

**依赖与产物。** S04–S06。交付版本化快照、IndexedDB 持久化、恢复接口与损坏/中断测试。

- [ ] 检查点由全队通过触发一次。快照保存模式、关卡版本、所有角色的状态/位置/速度/朝向、能量/凝聚/队形、救援、移动和跟随的必要历史、补给、世界相位、tick、触发器和路线。用一次事务写入完整记录，区分内存快照与最近已落盘快照。
- [ ] 重试从同一版本恢复完整状态，再应用约定的能量回满策略与默认跟随镜头。新会话从最近有效记录恢复，显示明确继续/重开动作。测试首次记录尚未落盘、读写失败、版本不匹配、快速连续重试及旧写入晚到，避免用过期状态覆盖有效记录。
- [ ] 比较恢复前后的状态与事件轨迹。验证剩余补给和叶轮相位一致、在快照之后选的路可重新选、已触发的提示不重放、暂停不会推进任何相位。先把 A 前的重开作为可试方案，和负责人确认后写入产品规则。

## S08 · 全员落脚与单次结算

**依赖与产物。** S05、S06、S07。交付同一 `Goal` 谓词、落脚阶段、结果事件和正常入口流程。

- [ ] 按权威名单和同一到达谓词生成 HUD 数字和成功条件。测试领队尚未到、11/12、12 名在区但有人离队/待救援、全员到且符合状态各条路径。校验名单有唯一领队和 11 名同伴。
- [ ] 开始落脚后冻结规则 tick 与失败判定；动画继续表现层播放。测试落脚与能量/救援阈值同 tick 的边界、掉帧、切后台、演出跳过与重复完成事件，最终只产生一次结果记录。

**放行证据**为小地图旅程成功、能量失败后重试、救援成功与超时重试、漫游软阻挡后落脚等可复现回放，连同七类 Zone 校验结果和固定时钟、快照差异报告。进入正式关卡后同一套规则继续运行。
