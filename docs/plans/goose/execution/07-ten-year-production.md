# 07 · 完整十年斑头雁线执行单

**依赖。** P0 S0–S6 已完成实机和音画验收，关卡版本、一次完整迁徙结果及存档格式归档。后续年度沿用相同的输入、队伍、恢复规则和可读性约束。先做连续两年的变体、独立的幕墙/夜灯样段与交接原型，结果用于设计其余年份。

| 任务             | 实施内容                                                                                                                     | 验收证据                                                                                              |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Y01 年度进度     | 类型、迁移、年份选择与年度记录。完成事件从 S6 同一出口进入原子结算。确认既有 P0 完成记录如何计入，以及重玩是否影响展示及传统 | 旅程和漫游交替推进，同一年度的重复事件、刷新、断电写入与读档只累计一次，旧档和坏档都有可解释的结果    |
| Y02 年份变体     | 同一基础地图按 `yearConfig` 配环境、风、补给、设施和光照。先记录玩家会怎么飞，再做模型和音乐变体                             | 相邻年份有可觉察的空间变化，均保有可达补给与通关路线。每年都可用独立关卡版本和输入复现                |
| Y03 路线传统     | 约三年重复选择形成传统。配已有地标、方向提示与声景，提供更早的可读信息和轻微跟随稳定收益                                     | 山口和长湖分别有传统推进录像。无传统可通关；默认镜头与静音仍有基础信息。重玩和 A 点反复停留不会刷进度 |
| Y04 幕墙         | 用 Three.js 先搭墙面、真开口、反光、清晰标线和防撞标识对照，观察默认与侧视准确读图，再评估模型/贴图来源                      | 玩家可在反应窗口辨别反光和真实通路。碰撞与渲染来自同一轮廓，所有画质保有标线、提示与真实出口          |
| Y05 夜灯         | 先搭河流、方向地标、灯场边界、熄灯街区与可预测的灯光节奏，再做水彩灯光和音乐变奏                                             | 正常及减少动态都能辨方向，暖光和光晕不会遮掉来路/通路。暂停、重试、读档后灯光相位一致                 |
| Y06 第十年与交接 | 编排最后一次全队落脚和年轻同伴交接，用镜头、姿态和音乐讲清关系。记录斑头雁线完成，供后续物种读取                             | 从第一年到第十年连续完成，演出跳过、刷新和继续都保留正确状态。鲸的可玩内容随 P2 实际交付              |

## 年度制作与验收顺序

1. 以 S0–S6 为首个年度候选，在后一年的配置证明可用同一地图改变风、湿地及选择。用两个变体验证传统提示与再次进入的完整体验。
2. 幕墙与夜灯先各做一个短灰盒。选择适用于 Web 的最低成本建模后，再按年份地图逐步编排。什么时候出现哪一种挑战、对队伍施加多少压力、是否有安静回望窗口，由试玩决定。
3. 为每一年填写「年度版本、环境变化、玩家新选择、已有传统提示、危险及正向对照、补给/检查点、自然声/音乐、回放」。复用关卡版本校验与静音、安全区、低能量、全员落脚测试，外加年度独有断言。
4. 完成一条从 P0 存档迁移到第十年的端到端回放，与一条新档交替使用旅程及漫游的通关回放。对最复杂的年度和第十年交接安排真实 iPhone/iPad 试玩，汇总每年变化是否能被察觉、路线传统是否易理解及交接是否有情感收束。

范围与未定规则见 [十年迁徙阶段计划](../06-ten-year-goose.md)和 [GDD §12](../../../../Feather_Tide_Gameplay_Design_v2.0.md)。
