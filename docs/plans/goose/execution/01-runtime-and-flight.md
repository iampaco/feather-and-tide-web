# 01 · 固定时钟、双手输入与飞行手感

**阶段交付**为可重复打开的飞行实验场。先用单雁和三类地标校准镜头与操控，再加入 11 只同伴、结阵和基本状态反馈。目标用户应能横屏用两手巡航、回看与修正航向。

## E02 · 固定步长与权威状态

**依赖与产物。** 基于现有 App 入口，在 `src/core/` 建立纯 TypeScript `GameRuntime`、命令、事件、只读快照及回放夹具，帧调度和页面生命周期放在 App。

- [ ] 使用 60 Hz 固定 tick，固定步骤顺序。记录实际消耗的世界输入，渲染从相邻快照插值。沿用 TDD 初始追步上限作为可配置工程值，暂停时清空帧累积器。
- [ ] 定义 `GameState`、`GameCommand`、`GameEvent` 及模拟阶段。输入设备和 Camera 留在表现侧。`actors` 保存稳定 ID，领队在名单中；UI 暂停通过公开命令进入模拟。
- [ ] 单测重放同一组按 tick 表示的移动命令，在达到同一 tick 时比较 30/60/120 FPS 帧计划的状态。覆盖超大 delta、重复暂停、后台长停留、继续后的第一帧，以及保存/恢复时前后插值基线重置。

## E03 · 版本化地图与校验入口

**依赖与产物。** 依赖 E02 的共享坐标/ID 契约。交付实验场 JSON、`LevelSchema`、共用校验入口、无效数据夹具和 CI 接线。

- [ ] 定义 `schemaVersion`、`levelRevision`、物种/模式规则、地图尺寸、段落和出生点。Zone、触发器、资产引用按 M2 逐类扩展。明确世界单位、+Z 前进与 XZ 逻辑平面。
- [ ] 运行时和 CI 使用同一校验逻辑。对未知版本、重复 ID、无效坐标、缺失引用和语义非法值给出关卡与字段。加载失败在正常入口展示重试或返回动作。

## I01 · 双手输入契约

**依赖与产物。** 先记录 ADR-009 的 GDD v2.0 契约、触点接管和 A/B 实验，再按共享接口实现 `src/input/`、DOM 交互层与 Pointer E2E。

- [ ] `pointerdown` 时按 UI、能力按钮、观察区、移动区分配职责。对接受的触点捕获 ID，保持职责直至抬起或取消。支持左移+拖镜、左移+能力两个主要组合。
- [ ] 统一 `pointerup`、`pointercancel`、`lostpointercapture`、窗口失焦、页面隐藏和暂停的释放路径。清空活动指针、键盘与能力状态，回前台需显式继续。键盘支持 WASD/方向键、Space、Esc，鼠标可以拖镜。
- [ ] 试验版包含镜像与大按钮，按实际可用区域摆放复位、暂停和能力。输入落在 UI 时优先由 UI 接管。横屏测试手指跨越三区与按钮滑入滑出，验证不会误触、丢输入或出现粘滞状态。

## S01 / R02 · 单雁飞行与镜头试验

**依赖与产物。** E02、E03、I01。交付单雁控制器、受限斜俯视相机、世界输入适配器及同一条 A/B 试飞路线。

- [ ] 用直线走廊、远处航标、宽弯和队尾观察点验证缓行、巡航、加速与转向上限。覆盖角度跨 ±π、逆向输入、摇杆死区边缘、加速松手后滑翔约 1 秒再低速盘旋。松手轨迹仍遵循碰撞规则。
- [ ] 镜头实现 `Follow`、`Explore` 与平滑复位。准备 `Focus`、`Cinematic` 意图接线给关卡与落脚。实测全角度领队可见、视角限位、地形遮挡纠正、玩家主动拖镜优先。建议初值为偏航 ±60°、俯视 35°–65°。
- [ ] A 采用实时投影并限制航向变化，B 固定移动手指按下时的方向基准。相同环境下交换试用顺序，记录误转、离线距离、复位次数及重新接手后航向变化。用固定世界指令测试镜头复位不写入模拟状态。

## S02 / S03 · 11 只同伴跟随与结阵

**依赖与产物。** S01。交付稳定队形 ID、一般跟随与 V 形槽位、可视形成度和参数配置。

- [ ] 采用路径历史/稳定槽位及局部分离。覆盖直行、急转、低速盘旋、加速后队尾延迟、窄弯与解除结阵。观察跟随误差、交叉、过度追赶、掉出构图，修正后保留回放。
- [ ] 从形成度推导 V 形收拢、转向限制与能耗系数。约 2 秒形成、约 1 秒舒展、完整阵型省力约 1/3 与转向速率约一半均为调参初值。快速按放不产生完整收益，急转能散阵，按住和点按切换走相同能力逻辑。
- [ ] 用同一条直线与弯道记录结阵和不结阵的朝向变化、队形包络和形成曲线。M2 接上能量后对比消耗，M3 再复测是否自然愿意解除结阵。

**放行证据**包括桌面和真实 iPhone/iPad 横屏操作、E2E 触点序列、可重放世界指令、镜头 A/B 记录，以及能读懂 12 雁收拢、松散和再集队的玩家录像。复核 [V2-01 至 V2-06、V2-17、V2-18](../05-verification-and-release.md)。
