# 05 · 音频、界面和体验打磨

**依赖。** S0–S6 灰盒提供稳定事件、画面提示及可交互路径，R00 已有 Web 导入样段。先完成 S0 起飞与安全观察，再补 S3 救援、S4 风场及保护湿地、S6 群体收束。所有音画响应仅消费只读状态和事件。

## A01 · 声景与动态配乐

- [ ] 清点主题旋律、风、水、振翅、远风机、雁群呼应与提示音的已有源和许可。当前 `Assets/Audio/` 是占位分类。两三段临时声景可用于打磨时序，再落实正式源文件。
- [ ] 实现 Web Audio 交互解锁、分轨音量和淡入淡出，允许环境与配乐独立控制。`MusicDirector` 读取模拟事件和当前阶段，按乐句或节拍过渡 Ambient、Journey、Focus、Tension、Care、Release。UI 及设置只调表现。
- [ ] S0 环境先行、起飞后主题进入，S1 队形收拢有可辨翼声，S2 山口与长湖有清晰音色差异，S3 雁呼应优先于配乐，S4 保护湿地保留自然声与松弛，S5 主题回归，S6 给全队短而完整的收束。
- [ ] 验证暂停、来电或后台、恢复、反复切换音量、检查点重试和演出跳过。音频恢复不叠加循环或重复提示，静音时有方向、轮廓、符号和文字等价线索。

## U01 · 从模式选择到落脚

- [ ] 接通真实菜单到旅程/漫游的共享地图。雁可开玩，鲸鹿显示“尚未开放”。加载失败、暂停和失败重试均提供直接可理解的动作，回前台是显式继续，读档带玩家回最近有效检查点。
- [ ] 只在适当时机展示教学、低能量、救援和已抵达人数。优先级依危险、救援、低能量、路线、教学安排。首次教学一次展示一条，能从操作完成退场并允许跳过镜头提示。
- [ ] 界面提醒玩家实际可以做的动作。S3 指出接应方向与靠近后的缓行，S4 提醒边界与外围，S5 提供可达补给方向，S6 明确等待队尾。用模拟状态检查 HUD 的触发条件、解除时机和数值。

## U02 · 横屏、双手与无障碍

- [ ] 按安全区布置暂停、复位、能力和临时提示，竖屏显示旋转提示。镜像时一起重排移动区、观察区和能力键，增大按钮后仍保留够用的拖镜区。
- [ ] 增加按住/点按切换、灵敏度、垂直转镜、复位速度/辅助的确认方案、减少运动、静音、关键提示文字与可区分的轮廓/图案。设置保存和重启后保持，控制方式变化时释放活动输入。
- [ ] 用桌面键盘操作菜单与暂停，检查可见焦点、按钮可达和键位提示。真实小屏实测拇指遮挡、左利手布局与连续使用能力的劳累。

## P04 · 四个镜头与音画节奏联合评审

| 片段       | 要看到或听到的层次                                   | 退回条件                                                     |
| ---------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| 起飞看湿地 | 先读前进方向、雁群与岸线，随后感到晨雾与主题展开     | 雾盖住航向、玩家动作被插播打断，或画面首次可交互明显晚于灰盒 |
| 山口/长湖  | 地标和侧风能解释两个选择，水声与风声加强差异         | 玩家必须靠长文字区分，或侧转镜头后只看见一个出口             |
| 河谷/风场  | 首先读到同伴和危险，声景加强动作反馈，湿地能安心停留 | 呼应被配乐盖住、危险与水彩融合到看不出、松手观景触发隐藏压力 |
| 团聚落脚   | 可看清所有雁陆续降落，结尾短而暖，有跳过或继续动作   | 镜头隐藏队尾、结算先于团聚，或重复播放造成第二次结算         |

每处保留灰盒和素材版的同机位截图、音画录像及关键事件的时序，按 [试玩执行单](06-playtest-and-release.md) 复测。目标是玩家能靠画面做决定，也有余裕欣赏风、水和队伍。
