# P1 · 完整斑头雁十年迁徙线

进入 P1 前完成 S0–S6 实机验收与首个关卡版本归档。P0 先保留一次迁徙完成事件、模式、所选路线和目的地记录。各年的叙事、环境变化和重玩语义在 P1 评审后确定。

| 次序                    | 工作内容                                                                                                                                   | 交付与验收                                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| P1.1 年份进度           | 定义 `MigrationProgress`、版本迁移、年度完成标识、年份选择与年度结果。通过一次原子结算更新年度记录与下一年，旅程/漫游共用进度              | 交替使用两模式可以推进到下一年。重复收到完成事件、重试、回到检查点或刷新页面时不会重复推进或重复增加路线计数。旧档迁移保留有效数据，坏档可恢复 |
| P1.2 年份变体与路径传统 | 基于共享地图与 `yearConfig` 调整湿地范围、风带、设施、保护措施与光照。路线累计约三年形成传统，以更早的羽迹、风标、呼应与轻微稳定性变化呈现 | 两路传统均有推进回放。默认视角和静音仍能看见基础预警，主动转镜能发现增量线索。无传统的路线保持可完成                                           |
| P1.3 新挑战与年度内容   | 分别制作幕墙原型与夜灯原型，探索防撞标识、熄灯街区等积极对照。验证通道、方向地标和预警，再为后续年份编排路线变体与音乐变化                 | 幕墙的真实通道与反光可分辨，夜灯环境能靠实际方向线索导航。每个新挑战先做灰盒通关再替换美术，每个年份至少有可完成路线与可达补给                 |
| P1.4 第十年与交接       | 全队落脚后交接年轻领队，用简短演出与声音收束斑头雁故事。记录雁线完成状态，供 P2 的鲸解锁条件使用                                           | 从第 1 年到第 10 年全程可验证，第十年只能结算一次，交接中断与重进有恢复路径。鲸可玩入口随 P2 实际交付开放                                      |

## 年份制作表

每年一行，先记录玩家能感知的变化，再确定资产投入。字段为「年份、地图版本、环境变化、路线/资源决策、已有传统提示、风险与保护措施、检查点、观景/音乐点、结算与回放」。先完成两年相邻变体、跨约三年的传统验证样例及第十年的交接原型，再补齐其他年份，校验前后变化的连续性。

## 需确认的进度规则

- 是否可重玩已完成年份，以及重玩能否覆盖展示记录。年度推进和传统计数须对同一次年度结算去重。
- 已有 P0 单次完成记录是否可以计入首年进度。明确迁移条件、默认值、用户提示与回退路径。
- 传统门槛与跟随增益、各年份的章节分布、交接后可操作内容。分别记录试玩依据与负责人确认。
