## 必须证明的玩法不变量

- **名单与结算。** 权威名单包含领队和全部同伴，离队者仍保留稳定 ID。HUD 和胜利共用到达谓词。测试 `11/12`、`12` 只在区但有人待救援、以及全部符合条件三种路径。进入落脚后冻结玩法判定，演出跳过、继续、刷新或重复事件只产生一次成功结算。
- **双手与镜头。** 每个 `pointerId` 在按下时绑定一种职责，直到抬起或取消。验证观察区滑入能力键、能力区滑入观察区、移动越区、失焦、后台、暂停和返回。固定世界输入下，镜头复位不会直接修改模拟数据。正常通过可用两只手完成。
- **旅程与漫游。** 旅程失败只来自安全/补给区外能量归零，或离队同伴计时归零。接触危险本身触发风险反馈和相应代价。漫游同图、无损失软阻挡、无失败与救援倒计时。围绕安全区边界、补给刷取、暂停和返回前台补回归测试。
- **完整恢复。** 断言重试能恢复全部角色及救援、阵型、凝聚、补给容量、风与叶轮相位、触发器、路线和模拟时钟。重试能量与镜头回默认按已确认策略处理。验证 A 点后可重选路线、旧/坏档处理、单次结算和持久化失败路径。
- **公平与可读。** S4 的可见轮廓与碰撞取同一关卡几何。用顶视和默认/侧视图复核接缝，并按实际巡航与滑翔测量约 3 秒预警窗口。S3 可在默认镜头与静音下定位接应目标，S5 低能量时有实际可达的补给或安全地。风险、救援和到达用形状、方向或文字提供音频与颜色之外的信息。
