# M4 · 水彩、角色动画、音频与界面

从通过灰盒验收的地图替换资产，并保留每段的通关回放、碰撞可视化和同机位截图。先在 S0 做一个整合样段，包含水彩湿地、共享雁模型、振翅与滑翔、俯视镜头和首段自然声。再扩到全路线。

## 音频与界面

- **A01 音频运行时。** Web Audio 由首次用户交互解锁；分别控制配乐、环境、提示声。`MusicDirector` 读取事件和状态，按 Ambient、Journey、Focus、Tension、Care、Release 层平滑过渡。游戏暂停、切后台、继续和静音均实测。先验收 S0 起飞、S3 救援呼应、S4 湿地与 S6 收束，再补齐全段。
- **A02 素材制作。** 清点已获授权的迁徙主题、风水声、振翅、呼应及界面提示。本目录的独立 `Assets/Audio/` 分类目前只有占位文件。确认可复用的源轨、许可再安排整合，其余可先用项目内临时声景验证交互节拍。
- **U01 流程。** 两模式进入、暂停、显式继续、段落失败重试、温和落脚与结算可通过正常入口完成。选择斑头雁可开玩，鲸与鹿标示“尚未开放”。加载、存档和 WebGL 中断都提供可理解的恢复动作。
- **U02 操作可访问性。** 保留镜像布局、放大按钮、能力按住/切换、灵敏度、垂直转镜、复位体验、减少运动、静音与文字提示。按 iPhone/iPad 横屏安全区布置，竖屏给旋转提示。风险、救援和路线用形状、轮廓、符号或文字表达，关键提示在两手遮挡下可读。

## 阶段出口

- 保留灰盒与素材版的 S2 两路入口、S3 救援、S4 默认/侧视角和 S6 落脚对照。确认关键轮廓与逻辑一致，关闭声音、开启减弱动态或降低画质后仍能通过。
- 用获准运行时资产构建并验证正常加载和损坏/缺失时的重试提示。留下文件来源、使用范围、授权证据、导出版本和体积。记录 iPhone/iPad 的首屏、热机帧时间与资源峰值，预算由实测决定。
