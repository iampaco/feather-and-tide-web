# M0–M1 · 工程契约与斑头雁飞行实验场

**交付物**为一个可在开发入口启动的安全实验场。玩家可主动飞行、转镜、复位和结阵，同屏显示 1 领队与 11 同伴。使用简单标记和开阔地标测试方向、视野与队形。

## M0 · 确立运行时与数据契约

| 任务                   | 工作内容                                                                                                                                                                                       | 验收                                                                                                                                |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| E02 固定步长与生命周期 | 在 `src/core/` 定义 `GameRuntime` 与 `GameState`、`GameCommand`、`GameEvent` 最小接口。模拟运行于固定 60 Hz，渲染读取前后快照插值，限制每帧追步。App 负责处理暂停、失焦、页面隐藏和 WebGL 中断 | 同一按 tick 编排的世界输入在 30/60/120 FPS 帧计划下得到容差内一致结果。暂停期间 tick 不变，继续时清除后台累积时间，并从中性输入开始 |
| E03 关卡数据入口       | 在 `src/levels/` 定义版本和引用约束，先覆盖实验场所需地图与出生点，再按 M2 扩展有效载荷。保留 `schemaVersion`、`levelRevision` 及物种/模式规则入口                                             | 加载前验证重复 ID、失效引用与版本。提交一个可复用的校验入口并接入 CI。报错能定位到关卡与字段                                        |
| E04 表现层接线         | 将测试场景反映到实际 App 初始化与错误路径，通过快照更新灰盒角色。设置与局部 UI 保持在 App / Presentation                                                                                       | WebGL 初始化失败显示恢复提示，图形中断暂停模拟，恢复后可显式继续。纯 Simulation 可在 Vitest 中独立执行                              |

交接时锁定 XZ 平面运动和 Y 表现高度，世界位置与相位归模拟所有。镜头读取快照，输入适配器再把摇杆/键盘意图映射到世界平面。回放录制映射后的世界指令，镜头手势和 A/B 映射另以 E2E 和实机任务验证。

## M1 · 从单雁到 12 雁

| 任务                   | 工作内容                                                                                                                                    | 验收                                                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| I01 双手输入           | 设计 ADR-009 提案和接口。左侧浮动摇杆，右空白区拖镜，独立能力键，显式复位。原型支持镜像和大按钮。桌面支持 WASD/方向键、鼠标拖镜、Space、Esc | `pointerdown` 捕获并固定职责，跨区不切换。`pointercancel`、失去捕获、失焦和暂停均释放输入。左移+拖镜及左移+能力分别成立     |
| S01 单雁飞行           | 摇杆死区和力度映射为缓行、巡航、加速。限制转向，松手先滑翔约 1 秒，再进入低速盘旋。所有参数集中配置                                         | 能明确区分速度档，反向输入渐转，松手轨迹可预期，玩家可完全控制航路                                                          |
| R02 主动镜头与方向试验 | 受限斜俯视跟随与观察，右手可调偏航、俯仰，松手平滑停住，支持平滑复位。实现 A 实时基准及 B 按下时锁定基准，用同一条测试航线进行 A/B          | 玩家边巡航边看前方和回望队尾。比较误转、偏离航线、复位次数与主观疲劳，记录实机机型和配置。单独复位不会直接写入领队/队伍状态 |
| S02 队伍 1+11          | `actors` 保存一份完整名单，领队与同伴使用稳定 ID。实现路径跟随、稳定槽位、邻近分离与队尾可观察反馈                                          | 弯道时不集体挤在中心、交叉换位或瞬移，能看出头尾距离变化。显示人数及所有目标均来自同一名单                                  |
| S03 结阵               | 用连续形成度驱动 V 形槽位、转向代价和后续能耗系数，支持按住与点按切换，量化急转散阵                                                         | 原型约 2 秒成阵、1 秒舒展，满阵转向约为正常的一半，快速按放无法生成完整增益。M2 验证实际能量减少约 1/3 的初值及其取舍       |

## 阶段出口

- 提供可启动的飞行实验场、固定输入回放、Pointer 事件 E2E，以及 iPhone/iPad 横屏实机记录。测试跨区、暂停回前台、镜像、按钮增大、双手遮挡以及镜头复位前后的模拟状态一致性。
- 试玩场景至少包含直线、宽弯、可回望的队尾和明显地标。记录镜头映射选择与理由，或保留两种候选并明确下一次验证条件。范围和原型参数见 [待决问题](07-decisions-and-backlog.md)。

依据见 [GDD §3–4、6.2、14–16](../../../Feather_Tide_Gameplay_Design_v2.0.md)及 [TDD §3–5、13、15](../../../Feather_Tide_Threejs_TDD_v1.0.md)。
