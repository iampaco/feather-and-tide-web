# 驯鹿篇 · 执行与验收记录

## 2026-11-22 · R0–R4 立体造型与构图

- R0 的前景覆雪松冠、树影和疏密不同的低植被区分松荫与开阔小径。R1 的涵洞增加内凹石拱、桥面边缘和潮湿坡脚。R2 用带斜撑的霜顶门柱、错落短门柱和收紧的窄口区分三种通过方式。
- R3 的矿坡使用不对称岩阶和坡脚碎石，背风处以板岩标记，恢复带用分簇矮灌与莎草体现层次。尘雾笔触读取固定 tick 的相位，受关卡区域轮廓约束。
- R4 增加弯折湿岸、浅水石、残雪和地图边界外的近远山脊。落脚降低默认俯角，仍按实际队伍位置取景。驯鹿 v002 使用共享的单网格与领鹿、幼鹿形态键，四个随动画的蹄部锚点用于接触影。[角色源与导出](../../../Assets/Watercolor/Deer/Blender/RD-CHR-001/v002/)
- 全套 285 项单元和集成测试通过。模拟横屏 WebKit 通过 40 项检查，包含两档画质、双手触控、涵洞回望、短弯触控、尘雾提示、全员落脚和旧检查点续玩。Chromium 键盘实走通过 R0 至 R4，经过 C1 刷新续玩、C2 保存和 9/9 落脚。
- 852 × 393 模拟横屏 WebKit 在 R1 路肩、R2 缺口、R3 分岔与 R4 苔原以两档画质各采样 180 帧。中位帧间隔为 16–17 ms，P95 为 19 ms，Draw Calls 为 36–46。实体 iPhone 与 iPad Safari 待测。
- ESLint、变更文件格式、资源清单和 Vite 生产打包通过。严格类型和关卡校验在排除现有 `whale-world 2.ts`、`whale 2.json` 副本的临时副本中通过。

## 2026-11-21 · R0–R4 场景美术升级

- R0 用霜松树群、低枝和树影围出冬林空地。雪坡起伏及渐隐坡脚位于原有障碍轮廓内。R1 用分块石拱、积雪路肩和远侧碎石空地标出涵洞与集队处，桥面按下方同伴位置剖视。车辆外形来自原有危险区尺寸，跟随原有车流相位。
- R2 宽口使用浅色柱帽和双道压实蹄径，短弯使用单线，窄口保留紧收的轮廓。R3 用层状矿坡、随尘雾相位变化的地面笔触、低矮板岩围出的背风地和浅金色补给植被区分两条路线。
- R4 在主蹄径和落脚区边缘加入带莎草的融雪浅滩，在可行走区域外补上灰紫山坡。驯鹿默认跟随角为 42°，复位返回该角度。默认落脚机位从全队位置取景，启用动态时向较低视角过渡。玩家的主动观察角度优先，宽幅鼠标环绕按实际树冠边界避让。
- 场景模型和着色为仓库内程序生成。雪坡、涵洞、围栏和矿区轮廓来自已有地面数据。浅滩、补给植被和尘雾边界在低画质下保留。[横屏前后对照](evidence/scene-art/R0-R4-before-after.jpg)
