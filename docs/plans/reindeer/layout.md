- **R1** 的涵洞坡道从 Z 108 到 120 下坡，从 132 到 144 回到地面，深 3 个世界单位。护墙保护两侧落差。位于墙内的鹿在路面投影下通行，车体和车道等候限制只作用于地面车道。路面的剖视遮罩帮助观察实际位置。
- **R2** 的窄口净宽 1.70，领鹿和体型较小的第一位同伴可从中央通过。其余同伴的碰撞直径为 1.88。宽口净宽 14，可让全队通过。玩家可循原缺口折返接应后转向宽口。
- **R3** 的尘雾边缘影响队伍凝聚与跟随，外绕恢复植被带有有限量补给和独立的安全休息地。两条路线都能从原始出生点走完全章。
- **C1 与 C2** 在安全地带。触发条件包括整支队伍真实到达和无待接应成员。其后都留有起步与回望空间。

回放的坐标、初始快照、输入和关键事件见[执行记录](execution.md)。

## `reindeer-p3-2` 体验布局

- R0 新雪堆在 X −8…8、Z 51…55，两侧引导线都能让九鹿通行；林缘增加集队空地。R1 涵洞几何及车流保持，入口雪坡明确弯入路径。
- R2 第一排保持 Z 267…269。第二排位于 Z 292…294，宽口 X −11…−1；第三排位于 Z 314…316，宽口 X 10…24。路线形成 S 弯，第一、二排之间及第三排之后留有安全地。窄口折返接应仍可完成。
- R3 近路沿 X +17 前进。尘雾为 Z 360…391、416…447，背风地为 Z 392…415，入口 Z 347…359 也可安全等候。恢复带从 X −47 绕过上段土坡，再回到 X −18 越过下段土坡。新增坡面可见并与碰撞一致，不能从地图外围抹平路线差。
- 所有地面引导线在关卡 `trails` 中声明，只有表现作用。地图、角色碰撞和队尾接应不由引导线自动控制。
- R4 引导经过 (0,533) → (12,545) → (0,559)，再进入原有开放落脚区。无新增硬危险。

## `reindeer-p3-3` 带队布局

- R0 松荫缓路在 X −25…−9、Z 40…75 可安全停步。开阔小径绕过雪堆另一侧，两路在近侧路肩汇合。
- R1 涵洞的 X 和 Z 范围保持原版。近侧集队点在 (−13.5, 103)，远侧在 (−13.5, 155)。过洞提示依据实际到达 Z144 的成员数。
- R2 首排新增 X −3.3…1.3 短弯入口，末排新增 X 0.7…5.3 短弯出口。短路和宽路共享中间宽口，两条路线都可由九鹿通过。首排领鹿能够通过的原窄口保持原净宽。
- R3 近路在第二雾带之后增加 Z 448…464 的出口缓坡。三处休息区连接两段尘雾，恢复植被带继续从另一侧绕行。
- R4 在 Z 533…551 的融雪弯内有一处安全观景坡，落脚区仍从 Z563 开始。
