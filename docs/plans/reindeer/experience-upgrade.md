# 驯鹿体验升级 · reindeer-p3-2

2026-11-20。用户确认保持首次通关 4–6 分钟、舒缓但需要照顾队伍，本轮加入周期尘雾；保留不能让全队通过的窄口，深化宽路。该时长是首次玩家试玩目标，尚非已验证的人体体验结论。

## 已实现

| 内容       | 玩家可见行为                                                   | 权威来源                                                                       |
| ---------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| R0–R1      | 积雪两侧选路、林缘停步、沿路肩弯入涵洞；可略过教学             | 关卡 barrier、trails 和既有公路几何                                            |
| 等候       | 呼唤进度与实际集队分开；按满但受阻、太远或待接应时不报全队已齐 | 纯函数 `reindeerGatherStatus`，停稳、following、10 单位内且无遮挡；呼唤半径 15 |
| R2         | 保留宽窄对照，宽路后增加两排错位围栏；指向当前受阻排的宽口     | 分排缺口计算与逐鹿扫掠碰撞                                                     |
| R3         | 近路两段尘雾、入口及中间背风地；恢复带绕行两段土坡并有有限补给 | 关卡几何、逐鹿尘雾采样及固定 tick                                              |
| 周期       | 平静 1200 tick、预告 240 tick、活跃 720 tick；活跃强度 0.55    | `dustCycle`；视听提示及模拟共用相位                                            |
| 路线与保存 | 汇流前折返可重选，汇流后锁定；旧修订说明后可返回或重新出发     | 既有 route、triggered、checkpoint 和 run record                                |
| R4         | 融雪缓弯连接原有开放落脚地；8/9 继续游玩，9/9 才落脚           | 原有全员到达谓词                                                               |

新增引导线 `trails` 只供地面蹄迹和色带绘制，模拟不会自动沿线导航。碰撞、队伍、失败、救援和胜利仍在纯 TypeScript 模拟中。没有新增运行时依赖或外部资产，模型与合成声源沿用现有授权素材。

关卡修订号更新为 `reindeer-p3-2`；状态和存档 Schema 仍为 1。旧版鹿位置快照不会迁移到新几何。读取旧档、展示说明或返回菜单均不写入旧记录，只有玩家明确开始新旅程后才进入既有新档流程。雁、鲸各自的存档与开放规则保留。

## 固定输入量测

[原始比较数据](evidence/experience-upgrade/route-comparison.json)来自当前 60 Hz 模拟，非真人首航或设备性能数据。

| 样本                              |      用时 | 汇流体力 |
| --------------------------------- | --------: | -------: |
| 同一分岔 80% 体力，近路连续巡航   |  53.75 秒 |   80.54% |
| 同一分岔 80% 体力，恢复带连续巡航 |  69.22 秒 |   96.30% |
| 同一分岔 15% 体力，恢复带连续巡航 |    同路线 |   59.18% |
| 整章安全近路，观察窗口并集队      | 241.62 秒 | 另见回放 |
| 整章恢复带连续巡航                | 221.92 秒 | 另见回放 |

近路纯行进样本节省约 15.47 秒。完整安全近路包含约 34.2 秒真实等候，计入相位后并不保证比恢复带更快。低风险地允许停留和观景，不用必然离队迫使玩家按能力。

两条主线、窄口折返、C1 救援超时重试和 C2 体力耗尽重试的新版输入分别保存在 [新版回放目录](evidence/experience-upgrade/)。原 `reindeer-p3-1` 证据保留，不再用来说明新版通过。

## 驯鹿带队体验 reindeer-p3-3

本轮优先处理 R2 的操作取舍。短弯的首尾缺口各净宽 4.6，和原宽路共享中间宽口。对齐入口、过栏再转时九鹿都能通过。提前切弯的对照回放中只有两只通过末排。领鹿折返到队尾一侧，在安全且无遮挡的位置呼唤，可引导受阻的同伴离开卡住的旧轨迹，再带九鹿过栏。

- R0 分岔提前显示松荫缓路和开阔小径。松荫的安全区可以停步练习呼唤。
- R1 近侧路肩可先收队或直接下坡。远侧先报告已到达成员数，再用世界标记指向还在洞里的队尾。固定输入抵达远侧路肩并停步时，有六只到达远侧，领鹿按等候后达到九只。
- R3 按实际位置显示下一处背风地、入区人数和尘雾相位。远侧新增可停步的出口缓坡。到下一处的用时按全队平静巡航估算，供玩家选择时机。
- R4 的融雪观景坡允许低体力安全停留，再继续至原落脚区。

同走恢复带的整章固定输入对照，宽路约 222 秒，短弯约 209 秒。原宽路和尘雾策略约 242 秒。三个样本均通过 C1、C2 到达 9/9。这里记录模拟用时，首次玩家 4–6 分钟及实体 Safari 输入仍按 [试玩单](device-playtest.md#p3-3-带队试玩)验证。

P3-2 的有效 C1、C2 可以在 P3-3 继续。快照保留原位置、队伍、世界 tick、路线和补给。P3-1 的旧地图仍通过原入口说明。

横屏 WebKit 画面见 [远侧路肩集队](evidence/p3-3/R1-gathering.png)、[两条全队通路及原窄口](evidence/p3-3/R2-openings.png)、[转镜查看过栏队尾](evidence/p3-3/R2-short-opening-tail.png) 和 [矿区中段收队](evidence/p3-3/R3-safe-pocket.png)。

当前构建通过 229 项 Vitest、严格类型检查、lint、关卡及资产校验。横屏 WebKit 的 10 项定向浏览器检查通过。Chromium 从标题页出发，穿过涵洞、刷新后从 C1 继续、通过宽路和恢复带并完成 [9/9 落脚](evidence/p3-3/R4-keyboard-landing.png)。另验证从 P3-2 的 C2 继续、等待 8/9、完成 9/9 并刷新读取已落脚记录。

## 驯鹿带队与尘雾取舍 `reindeer-p3-4`

冬林教学在领鹿绕过雪堆且实际队尾拉开后出现。涵洞远侧保留靠边呼唤和继续缓行，最后一只通过时都能看见 9/9。围栏在首排之前显示宽路与短弯，描深短弯的直行段，其端点从现有蹄迹和碰撞缺口计算。实际最后一只过栏后，提示转向。

矿区在两路分岔显示当前相位，并根据真实队尾位置和体力给出巡航、收队等雾或去恢复带的建议。走进活跃尘雾的同伴按各自暴露减速。队伍收紧后，以巡航通过时可以保持更短的间距，直到实际落回普通槽位。没有额外的必需按键或全局时钟。领鹿先进入背风地时，人数由逐鹿到达判定得出。两处检查点接受通过验证的 P3-2 和 P3-3 原快照，存档 Schema 仍为 1。

在第一处入口背风地 `(17,353)` 启动固定模拟。比较连续巡航与按等候 180 tick 后再巡航，记录领鹿到达 `Z406` 的实际入区人数和领尾最大纵向间距。

| 初始相位 tick | 连续巡航入区 | 先呼唤再巡航入区 | 最大纵向间距，连续巡航 → 先呼唤 |
| ------------: | -----------: | ---------------: | ------------------------------: |
|           420 |          8/9 |              9/9 |                    14.75 → 9.35 |
|           840 |          6/9 |              7/9 |                   18.83 → 16.70 |
|          1080 |          5/9 |              8/9 |                   20.42 → 15.51 |

若把提前收队与普通巡航都对齐到 tick 1080 出发，两组领鹿同 tick 到达，已进入背风地的成员为 7/9 和 5/9。领鹿进入背风地后，缓行到安全区深处可让落后的同伴赶上。典型的连续巡航、主动择时和恢复带整章回放均完成 9/9。记录的用时与间距来自 60 Hz 模拟，首航的选择、疲劳感和实机触感仍需试玩。

R4 从落脚前后的模拟快照确定最后符合到达条件的同伴。领鹿回望并呼唤，同伴回应，原声乐句在回应后稍抬起再淡出。减弱动态使用静态落脚姿态，静音和减弱动态都可从标记看见最后抵达的同伴。

验收通过 268 项 Vitest、严格类型检查、ESLint、Prettier、关卡与资产校验及启用驯鹿预览的生产构建。分轮通过 11 项 Chromium／模拟横屏 WebKit 验收，覆盖从标题跑完整章、刷新 C1、P3-2 C2 续玩和保存、车道禁用等候、真实队尾教学、短弯和回望、尘雾分岔与背风地，以及静音和减弱动态下的全员落脚。
