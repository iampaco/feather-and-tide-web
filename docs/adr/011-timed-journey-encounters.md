# ADR-011 · 三物种旅程的操作节奏

状态为已接受。2026-11-23，项目负责人选定短时操作序列，每种生物先调整三个遭遇。开场提供安全练习，主要遭遇要求主动改变方向或速度，后段复用同一操作。更精确的时机可节省时间或保持队形。较宽路线给迟转、错过窗口和能力未就绪的玩家留下调整空间。

- 雁 S0 提前展示芦苇绕行与滑翔。S1 将滑翔伞提示与选线提示错开，宽水面绕行浅滩，顺风短线可解阵斜切、转正并短加速。S5 根据阵风、背风入口与实际队尾距离提示转向和收速。
- 鲸 W0 教水面绕鱼群和浅潜借流。W1 用全深度防波堤引导先转弯，再选等船或深潜，最后一只鲸清船后提示上浮。W3 提示近航道静水出口及安静航道的第二股流。
- 鹿 R0 提前展示雪堆两侧小径。R2 根据每只鹿的碰撞半径与实际位置提示过栏和转向。R3 缩短露天尘雾，扩展下一处背风地，继续用原有周期与队尾距离评估出发窗口。

三个修订直接进入原旅程。顺风试飞与 S1 共用风场和浅滩数据。守住双手输入、固定模拟时钟、完整检查点、软失败和全员落脚。导引消息读取现有状态，风险与救援优先，静音和减少动态仍可辨认路线和队尾。`goose-p0-10`、`whale-p2-10`、`reindeer-p3-5` 沿用现有存档结构，继续读取同物种旧检查点。

自动化覆盖三个开场的提示时机、六条分支的 30/60/120 FPS 完整回放、快速与宽缓路线、历史存档和浏览器输入。每种生物的四次首次玩家观察和真实 iPhone/iPad 横屏触屏验收待执行，用于确认当前参数和提示节奏。
