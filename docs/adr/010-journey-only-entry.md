# ADR-010 · 仅保留旅程与生物选择入口

状态：已接受。2026-11-18，项目负责人明确要求删除漫游，只保留旅程；进入游戏先选三种生物，再进入有引导的旅程。本决议覆盖 GDD v2.0、TDD v1.0 和旧计划中的双模式要求，不改变移动、镜头、队伍和胜负不变量。

## 玩家流程

启动并加载 → 标题页「进入游戏」 → 斑头雁 / 鲸 / 驯鹿选择 → 对应物种的旅程引导。首次选择任一生物后直接进入引导。已有旅程检查点时，仍提供继续或重新出发的明确选择。

2026-11-23，项目负责人要求取消物种解锁。开发与生产构建均直接开放现有斑头雁 S0–S6、鲸 W0–W4 和驯鹿 R0–R4 旅程。此决议替代此前的鲸、鹿预览开关和跨物种解锁条件。

2026-11-19，项目负责人要求先展示现有晨雾湿地标题页，再由玩家确认进入独立的物种选择页。横屏以暖金湿地、蓝绿色海域、紫灰山谷并排呈现三种生物，竖屏纵向排列；选择页可返回标题或打开设置。标题提供练习飞行、规则试飞入口与原声试听。

## 契约与兼容

- `GameMode` 收窄为 `journey`，关卡 `modes` 只接受 `["journey"]`。保留字段和原旅程槽键，避免无必要的存档版本变化。
- 移除漫游规则、自动接应和专用接应参数。危险有接触代价；离队需要主动接应并走模拟倒计时；安全区外能量耗尽或救援超时可失败。
- 原旅程检查点及鲸物种槽继续读取。旧漫游槽保留在本地但不读取、不覆盖、不转成旅程；读档验证拒绝模式为 `roam` 的记录。
- 能力点按切换、减少动态、安全休息地及暂停继续保留。删除漫游不等于删除低风险观景空间。

## 验收映射

T17 的“漫游无失败”保障因明确产品变更退役，替换为“入口无漫游、关卡拒绝漫游、旧漫游存档不进入旅程、旅程危险与救援规则生效”。T23 验证首屏是标题页，确认后显示三种可选生物，首次玩家可直接进入任一物种的引导旅程。其余 T01–T16、T18–T23 与 V2 的相关输入、快照、暂停、全员到达保障继续保留。

原双模式回放留作历史证据，不能再作为当前版本通过验收的证据。设备与浏览器实测结果另见本次执行记录。
