# ADR-009 · 双手操作与镜头

状态为原型提案。依据 GDD v2.0 §3–4 更新 TDD §4 的输入契约。A/B 结论待实机试玩。

- DOM 控件先接管指针。能力按钮、观察区和移动区的命中只在按下时判定。接受指针后捕获 ID，移动越区维持原职责。普通松手解除该指针，取消、意外失去捕获、失焦、后台、暂停和设置变更释放全部输入。粗指针设备转成竖屏时沿用暂停流程，回到横屏后需明确继续。桌面窄窗口仍支持键盘与鼠标飞行。
- 输入向适配器提供屏幕向量和能力状态。相机单独接收拖动及复位。模拟按 tick 接收 XZ 世界向量和能力状态，命令记录可独立于镜头重放。
- 默认 Follow 为正交斜俯视。斑头雁 Explore 接受鼠标或触摸连续 360° 水平环绕，经典俯角为 35°–65°。新版通过默认关闭的「宽幅鼠标环绕」选项，将实际鼠标手势的俯角扩展到 20°–80°。宽幅观察平滑转向领队中心，遇到地形或设施时抬高实际俯角，在视线清除后回到请求角度。松手保留构图，复位从当前可见角度沿最短路径回到 49°。Focus 提供建议构图，玩家观察优先。Cinematic 在落脚期间锁定输入。
- A 每 tick 取当前可见镜头基准。B 在移动按下时锁定基准至松手。开启宽幅选项时，键盘使用偏航生成的单位长度地面基准，斜向组合键的航向与镜头俯仰解耦。经典档键盘与触摸继续使用现有地面投影比例。实验默认 A，设置可切换 B。
- 桌面可用鼠标左键或右键拖动空白场景，键盘移动与结阵可同时保持。R 将镜头复位指令发给表现层。加速与缓行同时按住时优先缓行，方便在保持方向键的同时收速。暂停或失焦后，仍按住的键须松开再按，自动重复按键不会重新接管输入。设置可保存主要键位，方向键、左 Alt 与 Esc 保持为固定快捷键。
- 每台真实 iPhone/iPad 横屏交换 A/B 顺序，记录偏离、误转、复位、恢复航向用时及疲劳。自动化验证跨区、组合输入、暂停释放与固定世界指令下复位隔离。物理设备记录与模拟 WebKit 报告分别保存。

## Web 0.1.0 证据

`flight-1` 可从标题进入。自动化已检查移动与拖镜并行、两类右手指针跨区、移动跨区、取消、失焦、按键、镜像与大按钮。复位仅发给 `CameraDirector`，固定世界输入回放没有相机字段。

Chromium 和横屏 WebKit 在同一安全实验场交换 A/B 执行次序。两轮使用相同的上推、右手横拖、滑翔、再次上推和复位序列。A 在持续按住时随镜头限速改变航向，B 保持起始航向并在重新按下时采用当时的镜头基准。按住复位时 B 继续沿新锁定的航向飞行。测试保存世界坐标、航向、镜头基准及截图。真实设备的偏离、误转、疲劳与恢复航向仍需按试玩执行单采集。
